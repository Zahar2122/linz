# Бот «Расписание линз»

Телеграм-бот на Python (aiogram 3), который напоминает, когда пора менять
контактные линзы.

## Возможности

- `/add` — добавить пару линз: название, интервал замены (однодневные,
  двухнедельные, месячные, квартальные или свой в днях), дата начала ношения.
- `/list` — список всех пар линз с датой следующей замены.
- `/delete` — удалить пару линз.
- `/settime` — во сколько присылать напоминание (по умолчанию 09:00).
- Ежеминутно бот проверяет, у кого сейчас настало время напоминания, и если
  для кого-то из линз сегодня наступила (или уже прошла) дата замены —
  присылает сообщение. Повторно за тот же цикл замены не напоминает.
- Поддерживаются несколько пар линз одновременно на одного пользователя.

Данные хранятся локально в SQLite-файле `lens_bot.db` (создаётся
автоматически при первом запуске).

## Установка

1. Получите токен бота у [@BotFather](https://t.me/BotFather) в Telegram:
   команда `/newbot`, следуйте инструкциям, скопируйте токен.

2. Установите Python 3.10+ и зависимости:

   ```bash
   python3 -m venv venv
   source venv/bin/activate        # на Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. Скопируйте `.env.example` в `.env` и впишите токен:

   ```bash
   cp .env.example .env
   ```

   В `.env` должно быть:

   ```
   BOT_TOKEN=ваш_токен_от_BotFather
   ```

4. Запустите бота:

   ```bash
   python bot.py
   ```

   Если всё настроено верно, в консоли появится строка `Бот запущен`.
   Найдите вашего бота в Telegram и отправьте `/start`.

## Постоянная работа (опционально)

Чтобы бот работал круглосуточно на сервере, есть варианты:

- **systemd (Linux):** создайте юнит-файл, который запускает
  `python3 /путь/к/bot.py` с `Restart=always`.
- **screen / tmux:** запустить `python bot.py` внутри сессии, которая не
  закроется при отключении от сервера.
- **Docker:** можно обернуть в контейнер (Dockerfile не входит в этот набор,
  но структура проекта это легко позволяет — просто скопируйте
  `requirements.txt` и код в образ на базе `python:3.12-slim`).
- **Бесплатный хостинг Render (см. ниже)** — не нужен свой сервер вообще.

## Бесплатный деплой на Render через GitHub

Бот уже умеет работать в двух режимах и переключается автоматически:
- **локально** — обычный polling (просто `python bot.py`);
- **на Render** — через webhook (сам понимает, что он на Render, по
  переменной окружения `RENDER_EXTERNAL_URL`, которую Render выставляет
  автоматически).

Ничего вручную переключать не нужно — один и тот же код работает в обоих
случаях.

### Шаг 1. Загрузить код на GitHub

1. Зарегистрируйтесь на [github.com](https://github.com) (бесплатно).
2. Создайте новый репозиторий (кнопка **New repository**), например
   `lens-bot`. Сделайте его **Private**, если не хотите, чтобы код видели
   посторонние (токен там всё равно не хранится, но так спокойнее).
3. Загрузите файлы одним из способов:
   - **Через браузер** (проще всего): на странице репозитория нажмите
     **uploading an existing file** и перетащите все файлы из папки
     `lens_bot` (кроме `.env`, если вы его создавали, и папки `venv`).
   - **Через git** (если установлен):
     ```bash
     cd lens_bot
     git init
     git add .
     git commit -m "Первая версия бота"
     git branch -M main
     git remote add origin https://github.com/ВАШ_ЛОГИН/lens-bot.git
     git push -u origin main
     ```

   Файл `.env` **не загружайте** — он уже в `.gitignore`, там ваш токен, и
   ему не место в общем репозитории. Токен будет вставлен отдельно в Render.

### Шаг 2. Развернуть на Render

1. Зарегистрируйтесь на [render.com](https://render.com) — можно через
   аккаунт GitHub, карта не нужна.
2. Нажмите **New** → **Web Service**.
3. Выберите репозиторий `lens-bot` из списка (Render попросит разрешить
   доступ к GitHub — разрешите).
4. Render подхватит настройки из `render.yaml` автоматически
   (Runtime: Python, план: Free). Если попросит указать вручную:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python bot.py`
5. В разделе **Environment** добавьте переменную:
   - `BOT_TOKEN` = ваш токен от @BotFather
6. Нажмите **Create Web Service**. Render соберёт и запустит бота — это
   займёт пару минут. В логах должна появиться строка
   `Бот запущен в режиме webhook: ...`.
7. Готово — найдите бота в Telegram и напишите `/start`.

### Важно знать про бесплатный план Render

- Сервис «засыпает» после ~15 минут без запросов. Первое сообщение после
  этого бот получит с задержкой 30–50 секунд, пока сервис «просыпается» —
  дальше отвечает мгновенно. Для личного бота это некритично.
- **База данных не переживает передеплой.** Файл `lens_bot.db` хранится на
  диске сервиса, но при каждом новом деплое (например, если вы обновите код
  на GitHub) диск пересоздаётся, и добавленные линзы придётся вносить заново.
  Если это станет проблемой — напишите, подключим бесплатную внешнюю базу
  (например, Turso или Supabase), чтобы данные не терялись.
- Любое обновление кода: измените файлы в GitHub-репозитории → Render сам
  подхватит изменения и передеплоит бота (если включён Auto-Deploy, он
  включён по умолчанию).

## Возможные доработки

- Часовой пояс пользователя (сейчас время сервера).
- Уведомление за N дней до замены, а не только в день замены.
- Инлайн-кнопка «Я поменял(а) линзы сегодня» для быстрого сброса цикла.
- Хранение статистики/истории замен.
